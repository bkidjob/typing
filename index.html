Features

Powerful Features for Serious Learners

Everything you need to improve your typing speed and accuracy, backed by intelligent analytics.

⌨️

Interactive Keyboard Heatmap

Visualize your typing performance in real-time with speed and error heatmaps. Identify weak keys and track improvement over time with our responsive QWERTY keyboard visualization.

🎨

Beautiful Editor Themes

Choose between Atom One Light and One Dark themes. Fully responsive color schemes designed for comfortable, extended practice sessions without eye strain.

Smart ASCII Normalization

Type special characters and accented letters (é, ñ, ß, ≤) using standard QWERTY layouts. Custom character mappings let you define your own replacement pairs.

🤖

Local LLM Integration

Connect to local AI endpoints (Ollama, LM Studio, Qwil) for smart text cleanup, difficulty estimation, and personalized typing coaching suggestions.

📊

Adaptive Lesson Generation

Get custom lessons generated based on your trouble keys and performance stats. The system learns from your mistakes and creates targeted practice exercises.

💡

Contextual Insights Panel

Receive AI-powered explanations for code snippets or sentences as you type. Automatically updates when you complete each line with relevant context and tips.

📈

Progress Tracking & Analytics

Track your WPM, accuracy, and session history with detailed charts. Monthly calendar view shows practice intensity and streak tracking keeps you motivated.

💾

Offline-First Storage

All your data is stored locally using chrome.storage and IndexedDB. Export/import your entire profile, lessons, and statistics with JSON backup utilities.

🎯

Custom Lessons & Code Practice

Practice with preloaded lessons in Rust, HTML, CSS, JavaScript, or import your own text files. Perfect for developers wanting to improve coding speed.
