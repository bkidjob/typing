How It Works
Step 1

Pick a Lesson and Start Typing

Select from preloaded Rust, HTML, CSS or JavaScript lessons, import your own text files, or let the adaptive engine generate a lesson from your trouble keys.

Step 2

See Your Speed and Errors in Color

The on-screen keyboard lights up with real-time heatmaps — blue for fast keys, red for slow or error-prone keys. You and your coach will know exactly where to focus.

Step 3

Get AI Insights Without Sending Data to the Cloud

Connect Ollama, LM Studio or any OpenAI-compatible local server. Get contextual explanations for the code line you just typed, difficulty ratings for imported material, and adaptive lessons targeted at your weakest keys.

Step 4

Track Progress and Set Practice Goals

A monthly calendar heatmap, WPM progression charts, and sortable session history turn every practice session into a measurable improvement. Set daily character-minimum goals and enforce offline lockout to keep your habits consistent.

Privacy

Adaptive Typing Trainer collects only what it needs — and everything stays on your device.

  • No user accounts, no email, no name.
  • All sessions, key statistics, lessons and schedules are stored in IndexedDB on your machine.
  • User preferences (theme, keyboard layout, cursor style) live in chrome.storage.local.
  • The optional LLM API key is stored locally; only configured users send data to a local server.
  • No data is sold or shared with third parties.
  • No remote scripts — the extension loads only its own bundled files.
