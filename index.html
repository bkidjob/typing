How It Works
↑ Toggle on to zoom screenshots
Step 1

Pick a Lesson and Start Typing

Select from preloaded Rust, HTML, CSS or JavaScript lessons, or import your own text files. The on-screen keyboard lights up with real-time heatmaps as you type.

Step 2

Get Contextual AI Explanations

As you type, a local LLM provides real-time explanations of the code or text you're practicing. The Context Insights panel shows what each line means, why it matters, and how to improve — all without leaving the typing flow.

Step 3

Import Custom Lessons

Paste any code or prose to create a custom lesson instantly.

Step 4

Track Progress and Set Goals

A monthly calendar heatmap, WPM progression charts, and sortable session history turn every practice session into measurable improvement. AI-powered coach diagnostics give you personalised feedback on speed, accuracy, and sustained performance.

Step 5

Configure Everything Locally

Connect Ollama, LM Studio or any OpenAI-compatible local server for AI insights. Fine-tune themes, keyboard layouts, cursor styles, and character mappings — all stored on your device with no cloud dependency.

Privacy

LLM Typing Trainer collects only what it needs — and everything stays on your device.

  • No user accounts, no email, no name.
  • All sessions, key statistics, lessons and schedules are stored in IndexedBD on your machine.
  • User preferences (theme, keyboard layout, cursor style) live in chrome.storage.local.
  • The optional LLM API key is stored locally; only configured users send data to a local server.
  • No data is sold or shared with third parties.
  • No remote scripts — the extension loads only its own bundled files.
