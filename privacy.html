Adaptive Typing Trainer — Privacy Policy

Last updated: July 2026

Scope

This Privacy Policy describes how the Adaptive Typing Trainer Chrome Extension ("extension", "we", "our") collects, uses, stores, and shares your data when you use the extension in Google Chrome.

Data We Collect

Typing Sessions

Each typing session produces metrics stored locally in IndexedDB:

  • Words per minute (WPM) and characters per minute (CPM)
  • Accuracy percentage
  • Error count and duration
  • Session timestamp and challenge title

Key Statistics

Per-character performance data is stored in IndexedDB:

  • Total presses per character
  • Average press latency (milliseconds)
  • Error count per character

Lesson Content

Text from lessons — both preloaded and user-imported — is stored locally in IndexedDB for practice purposes.

  • Includes code, prose, or any text the user imports.
  • No metadata (filename, author) is collected from imported files.

User Preferences

The following settings are stored in chrome.storage.local:

  • Theme (Atom One Light / Atom One Dark)
  • Operating system profile (macOS, Windows, Linux)
  • Keyboard form factor (MacBook, Desktop ANSI, Desktop ISO)
  • Logical layout (QWERTY, Dvorak, Colemak)
  • Finger guide visibility
  • Error behaviour (stop cursor / forgive from error) and whitespace display style
  • Custom character mappings (e.g. ß → ss)

LLM Endpoint Configuration

If you configure a local LLM, these values are stored in chrome.storage.local:

  • Endpoint URL (e.g. http://localhost:1234/v1)
  • Optional API key (bearer token)
  • Model identifier

Practice Schedule & Lockout Goals

Daily goals (character count, time limit, auto-pause) and lockout expiry timestamps are stored in IndexedDB and chrome.storage.local.

LLM Query Payloads (network traffic only)

When you use the Insights Panel or Adaptive Lesson Generation, the following data is sent to your configured LLM endpoint:

  • The text of the current code line or sentence being typed
  • Your most common error characters and trouble keys (for lesson generation)

Data We Do Not Collect

  • No personally identifiable information (Name, email address, phone number, or profile picture)
  • No health or biometric data
  • No financial or payment information
  • No personal communications (email, messages, chats)
  • No device location (GPS or Wi-Fi triangulation)
  • No web history (pages visited outside the extension tab)

How We Use Your Data

Data is stored and used solely for the extension's core features:

  • Typing speed and accuracy tracking — WPM, CPM, and accuracy charts
  • Keyboard heatmaps — speed and error overlays on the virtual keyboard
  • Adaptive lesson generation — generating lessons focused on your trouble keys
  • Practice scheduling — daily goals, offline lockout enforcement, progress calendar
  • LLM insights — contextual explanations for lines or paragraphs you are typing
  • Profile backup & restore — JSON export/import for migration or archiving

Data Sharing

We do not sell or share user data with any third party.

The only clientside network requests leave your device are to your own configured LLM endpoint (e.g. Ollama running at http://localhost:1234). That server may store responses briefly in its own cache; this extension does not control that server.

Data Storage

All extension data persists on your device after you close the browser tab:

  • IndexedDB — sessions, key statistics, lesson text, schedule goals (located under chrome-extension:// origin storage)
  • chrome.storage.local — user preferences, LLM endpoint, API key (also persisted locally)

Data can be cleared when you uninstall the extension or manually via the Backup & Restore settings panel.

Children's Data

This extension does not target children under the age of 13 and does not collect any data from children. It is designed for general audiences.

Data Security

All data is stored locally — no cloud databases. The extension uses a Content Security Policy (CSP) that blocks remote script blob injection, and all dynamic HTML content is wrapped in a sanitiser that strips <script>, <iframe>, and event handler attributes before injection.

Your Rights

  • Export — Use the built-in Backup feature to download a complete JSON archive of all your sessions, lessons, key statistics, and preferences.
  • Clear — Uninstall the extension or clear its site data via Chrome settings (Settings → Extensions → Extension details → Site data).
  • Edit — Import custom lessons, edit custom character mappings, or adjust any displayed values at any time.

Changes to This Policy

If we materially change how data is collected or shared, we will update this page and set a new "Last updated" date. Updates are effective immediately upon publication.

Contact

For questions about this privacy policy or our data practices, visit the GitHub repository for Adaptive Typing Trainer and open an issue.
